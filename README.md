# VECTORE-DE-OBJETOS

# Inventario con Vector de Objetos

## Descripción del programa
Este programa nos permite gestionar un inventario de productos, utilizando un STRUCT y un VECTOR. Cada producto tiene dos atributos, nombre y precio, y el sistema permite registrar varios productos en un solo vector, también mostrar la lista completa de productos con sus precios, también nos permite modificar el precio de un producto accediendo por índice, por igual también calcular el promedio del inventario y por último nos permite acceder de forma segura a un producto usando "at()".
